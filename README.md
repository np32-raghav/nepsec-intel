# NepSec Intel — Static Website

A responsive static website built with plain HTML, CSS and JavaScript. No framework, backend, database or build process is required.

## Run locally
1. Extract the folder.
2. Open `index.html` in a browser.

For local development, you can also run a simple server from this directory:
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Before publishing
- Replace `hello@kuinkel.com` in `index.html` with the correct contact email.
- Replace the illustrative dashboard values with approved content if needed.
- The dashboard is a visual demo; it does not connect to live threat feeds.
- Update page copy, branding and links to match your final requirements.

## Deployment
Upload `index.html`, `styles.css` and `script.js` to any static hosting provider, such as GitHub Pages, Netlify, Cloudflare Pages or an ordinary web server.
